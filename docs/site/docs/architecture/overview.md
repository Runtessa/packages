IdpCore is a multi-service platform with these primary domains:

- **Core runtime**: tenant dispatch, module/UI execution, ACL enforcement, shared adapters.
- **IDE**: editing, publishing, revisioning, assistant workflows.
- **Auth**: tenant SSO/OAuth, profile, org and role management.
- **Infrastructure agents**: container manager, monitoring, codex gateway.

The documentation pipeline auto-builds route and service inventory from source code.
