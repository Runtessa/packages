Major Runtime Boundaries

Core Runtime
Express + TypeORM

Executes backend modules, enforces tenant/auth/ACL context, hosts public registry and auth APIs.

IDE
Next.js Control Plane

Admin pages, editor UX, code save/build/migration flows, monitoring dashboards and alert rule management.

Kernel
Browser Runtime

Loads UI packages, resolves runtime dependencies, and injects tenant auth token into fetch.

Shared Entities
@idp/shared

Common entity contracts and tables used by core and IDE APIs.

Operational Notes

  • Monitoring collection is non-blocking and out-of-band from request handling.
  • Sampling cadence is constrained to under 5 seconds for near-real-time charts.
  • Monitoring UI now separated by scope pages: overview, instances, tenants, alerts.
